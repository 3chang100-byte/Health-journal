# 카카오톡 업무 대화 정리

카카오톡 대화 내보내기 파일을 읽어 업무 내용을 정리하고, 과거 대화에서 일정·아이디어·결정사항을 찾아 답한다.

## 전제: 대화를 가져오는 방법

카카오톡은 대화방 내용을 읽을 수 있는 공식 API가 없다. 대화는 반드시 **대화 내보내기 파일**로 들어온다. 서버에서 실시간으로 읽어 오는 척하지 말 것. 파일이 없으면 없다고 말하고 내보내는 방법을 안내한다(`references/export-guide.md`).

## 작업 폴더

사용자가 Cowork에서 선택한 폴더 안에서 아래 구조를 쓴다. 없으면 만든다.

```
카카오톡/
├── 내보내기/        사용자가 내보낸 파일을 넣는 곳 (.txt .csv .zip)
├── 정리/            정리 결과 (YYYY-MM-DD 업무정리.md)
└── 보관함.jsonl     지금까지 읽은 모든 대화 (중복 없이 누적)
    상태.json        마지막 정리 시점, 업무 대화방 목록
```

대화 파일은 `내보내기/` 밖에 있을 수도 있다. 대화에 첨부된 파일, 그리고 선택 폴더 안의 `KakaoTalk_*.txt`, `KakaoTalkChats*.txt`, `Talk_*.txt`, `KakaoTalk_Chat_*.csv` 도 찾아본다.

## 1단계: 대화 불러오기

파서는 이 스킬 폴더의 `scripts/kakao_parse.py` 다. 원본 파일을 직접 통째로 읽지 말고 항상 파서를 거친다(형식이 기기마다 다르고 파일이 매우 클 수 있다).

```bash
# 새 파일을 보관함에 합치고 대화방 현황 확인
python3 <스킬폴더>/scripts/kakao_parse.py "카카오톡/내보내기" --archive "카카오톡/보관함.jsonl" --stats

# 이후 조회는 보관함을 대상으로
python3 <스킬폴더>/scripts/kakao_parse.py "카카오톡/보관함.jsonl" --since "2026-11-20 09:00"
python3 <스킬폴더>/scripts/kakao_parse.py "카카오톡/보관함.jsonl" --days 7 --room 영업
python3 <스킬폴더>/scripts/kakao_parse.py "카카오톡/보관함.jsonl" --keyword 회의 --keyword 미팅 --context 3
```

옵션: `--since/--until`, `--days N`, `--room`, `--sender`, `--keyword`(여러 개, OR), `--context N`, `--room-name`(방 이름을 알 수 없는 파일에 직접 지정), `--format jsonl`.

- 파일이 하나도 없으면: `references/export-guide.md` 를 읽고 사용자의 기기에 맞는 내보내기 방법을 안내한 뒤 멈춘다. 컴퓨터 조작 도구가 있고 카카오톡 PC 앱이 열려 있다면 같은 문서의 "직접 내보내기" 절차를 제안할 수 있다(사용자 동의 후에만).
- 방 이름이 날짜나 파일명처럼 나오면(iOS 내보내기) 어떤 방인지 한 번 묻고 `상태.json` 에 기억한다.
- 출력이 너무 길면(대략 수천 건 이상) 기간이나 방을 나눠 여러 번 읽는다. 잘라낸 채로 "전부 읽었다"고 하지 않는다.

## 2단계: 요청 유형에 따라 처리

### A. "카카오톡 업무내용 정리" (정기 정리)

1. `상태.json` 의 `마지막_정리` 이후 대화를 읽는다. 처음이면 최근 7일. 사용자가 기간을 말하면 그 기간.
2. `상태.json` 에 `업무_대화방` 목록이 있으면 그 방만 본다. 없으면 `--stats` 결과를 보여 주고 어떤 방이 업무용인지 한 번 물어 저장한다.
3. `references/extraction-guide.md` 의 기준으로 분류해 아래 형식으로 정리한다.
4. 결과를 `카카오톡/정리/YYYY-MM-DD 업무정리.md` 로 저장하고, 대화창에는 핵심만 짧게 보여 준다.
5. `상태.json` 의 `마지막_정리` 를 이번에 읽은 마지막 메시지 시각으로 갱신한다.

정리 형식:

```markdown
# 카카오톡 업무정리 (기간: 11/19 ~ 11/21)

## 📅 일정
| 날짜·시간 | 내용 | 대화방 | 말한 사람 | 상태 |
| 11/24(화) 14:00 | 거래처 미팅 | 영업팀 | 김팀장 (11/19) | 확정 |

## ✅ 할 일
- [ ] **내 할 일** 견적서 초안 공유 — 기한 11/20(금), 영업팀, 김팀장 요청
- [ ] (이대리) 발표 자료 준비 — 기한 미정

## 📌 결정사항
- 워크숍 장소 확정 — 기획방, 11/20

## 💡 아이디어·제안
- 견적서 템플릿화 (박사원, 영업팀 11/20) — 후속 논의 없음

## ❓ 답이 필요한 것
- 정대표: 계약서 월요일까지 검토 요청 — 아직 답 없음

## 대화방별 한 줄 요약
```

해당 항목이 없는 섹션은 뺀다.

### B. 특정 내용 질문 ("카톡에서 나온 일정", "그때 그 아이디어", "누가 뭐라고 했지")

1. 먼저 `내보내기/` 에 새 파일이 있으면 보관함에 합친다.
2. 질문에서 기간, 방, 사람, 주제를 뽑아 필터를 건다. 주제어는 동의어까지 `--keyword` 로 여러 개 준다(예: 일정 → 회의, 미팅, 일정, 약속, 마감, 까지, 시, 요일). 키워드로 못 찾으면 기간만 걸고 통째로 읽어 의미로 찾는다.
3. 답에는 항상 **대화방, 날짜, 말한 사람**을 붙인다. 보관함의 마지막 메시지 시각도 함께 알려 "이 시점까지의 대화 기준"임을 밝힌다.
4. 못 찾았으면 못 찾았다고 말하고, 보관함이 다루는 기간과 방을 알려 준다. 추측으로 채우지 않는다.

### C. 후속 작업 (사용자가 원할 때만)

정리 후 한 줄로 제안하고, 승인받은 항목만 실행한다.

- 일정 → 연결된 캘린더(구글 캘린더, 톡캘린더 등)에 등록. 등록 전 날짜·시간·제목을 표로 보여 주고 확인받는다.
- 할 일 → 연결된 할 일/노션 등에 추가.
- 요약 → 카카오톡 "나와의 채팅"으로 보내기(도구가 있을 때).

다른 사람에게 메시지를 보내거나 대화방에 글을 올리는 일은 하지 않는다.

## 해석 규칙

- "내일", "다음주 화요일", "금요일까지" 같은 표현은 **그 메시지가 쓰인 날짜**를 기준으로 실제 날짜로 바꾼다. 요일도 함께 적는다. 연도·날짜가 애매하면 "추정"이라고 표시한다.
- 일정이 나중에 바뀌거나 취소되었으면 최신 상태만 일정표에 올리고 변경 이력을 한 줄로 남긴다.
- "내 할 일"을 구분하려면 사용자의 카카오톡 이름을 알아야 한다. `상태.json` 의 `내_이름` 을 쓰고, 없으면 한 번 묻는다. 내보내기 파일에서 본인은 "회원님"으로 나올 수 있다.
- 사진, 동영상, 이모티콘, 파일 메시지는 내용이 없다. 그 주변 대화에서 의미가 있을 때만 "파일 공유됨" 정도로 언급한다.
- 잡담, 인사, 식사 얘기 등 업무와 무관한 내용은 뺀다.

## 개인정보

대화에는 다른 사람의 개인정보가 들어 있다. 보관함과 정리 파일은 사용자의 작업 폴더에만 둔다. 사용자가 요청하지 않은 외부 서비스로 대화 원문을 보내지 않는다. 업무와 무관한 사적인 내용(건강, 가족, 연봉 등)은 정리에 옮기지 않는다.

## 상태.json 형식

```json
{
  "내_이름": "홍길동",
  "업무_대화방": ["영업팀", "기획방"],
  "방_이름_매핑": {"Talk_2026.11.20 10:30-1": "재무방"},
  "마지막_정리": "2026-11-20T16:00"
}
```
