# 분류 기준

한 메시지가 아니라 **대화 흐름**을 보고 판단한다. 제안 → 반응 → 확정까지 이어서 읽는다.

## 일정
날짜나 시간이 붙은 약속, 회의, 방문, 행사, 마감.
- 신호: "~시에", "~요일", "12/3", "다음주", "미팅", "회의", "방문", "납품", "오픈", "마감"
- 상태 구분: **확정**(동의·확인이 있음) / **제안 중**(답이 없거나 조율 중) / **변경** / **취소**
- 장소, 참석자, 준비물이 언급되면 함께 적는다.
- 기한만 있는 일("금요일까지 보내주세요")은 일정이 아니라 할 일의 기한으로 넣는다.

## 할 일
누군가 하기로 했거나 요청받은 행동.
- 신호: "~해주세요", "부탁", "~하겠습니다", "제가 ~할게요", "확인 바랍니다", "공유드릴게요"
- 담당자, 기한, 요청한 사람을 적는다. 담당자가 불분명하면 "담당 미정".
- 이후 대화에서 "보냈습니다", "완료" 가 나오면 완료로 표시하거나 뺀다.
- 사용자 본인 몫을 맨 위에 **내 할 일**로 올린다.

## 결정사항
논의 끝에 정해진 것. 금액, 수량, 업체, 방식, 담당 등.
- 신호: "~로 하죠", "확정", "승인", "그렇게 진행", "결정"
- 숫자(금액, 수량, 날짜)는 원문 그대로 옮긴다. 바꾸거나 반올림하지 않는다.

## 아이디어·제안
아직 결정되지 않은 생각, 개선안, 해보자는 얘기.
- 신호: "~하면 어떨까요", "아이디어", "제안", "~해보면", "생각인데"
- 누가 냈는지, 반응이 어땠는지(호응 / 보류 / 후속 논의 없음)를 붙인다.
- 흘려 지나간 아이디어도 놓치지 않는다. 이 섹션이 사용자가 가장 다시 찾고 싶어 하는 부분이다.

## 답이 필요한 것
사용자에게 온 질문이나 요청 중 대화에서 아직 답이 보이지 않는 것. 사용자 이름이 호명되었거나 "@이름" 으로 언급된 것을 우선한다.

## 주의
- 대화에 없는 내용을 추측해 채우지 않는다. 애매하면 "확인 필요"로 표시한다.
- 같은 항목이 여러 방에서 나오면 하나로 합치고 방 이름을 모두 적는다.
- 각 항목에 출처(방, 날짜, 말한 사람)를 남겨 사용자가 원문을 찾아볼 수 있게 한다.
