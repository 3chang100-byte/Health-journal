# 카카오톡 대화 내보내기 안내

사용자의 기기에 맞는 것만 골라 짧게 안내한다. 메뉴 이름은 카카오톡 버전에 따라 조금 다를 수 있으니, 다르면 비슷한 이름의 메뉴를 찾도록 안내한다.

## PC (Windows) — 가장 편함

1. 대화방 열기 → 오른쪽 위 ≡ 메뉴 → **대화 내용** → **대화 내보내기**
2. 저장 위치를 Cowork 작업 폴더의 `카카오톡/내보내기/` 로 지정
3. `KakaoTalk_날짜_시간_방이름.txt` 형태로 저장됨

## Mac

1. 대화방 열기 → 오른쪽 위 메뉴(또는 상단 메뉴 **채팅방**) → **대화 내용 저장** / **대화 내보내기**
2. `.csv` 또는 `.txt` 로 저장됨 → `카카오톡/내보내기/` 에 넣기

## Android / iPhone

1. 대화방 → 오른쪽 위 ≡ → 설정(톱니바퀴) → **대화 내용 내보내기** → **텍스트만 보내기**
2. 메일이나 클라우드 드라이브로 자신에게 보낸 뒤 PC의 `카카오톡/내보내기/` 에 저장 (.txt 또는 .zip 그대로 넣어도 됨)
3. iPhone 파일은 이름에 방 이름이 없다(`Talk_날짜.txt`). 방 이름으로 된 하위 폴더에 넣거나 파일 이름을 방 이름으로 바꾸면 자동 인식된다.

## 알아둘 점

- 같은 방을 여러 번 내보내 넣어도 된다. 겹치는 메시지는 자동으로 한 번만 저장된다.
- 내보내기 파일은 내보낸 시점까지의 대화만 담는다. 최신 내용을 보려면 다시 내보내야 한다.
- PC 앱은 그 PC에 로그인한 뒤 받은 대화 위주로 내보내질 수 있다. 오래된 대화가 필요하면 모바일에서 내보낸다.
- 여러 방을 정기적으로 본다면 주 1회나 매일 퇴근 전 업무 방만 내보내는 습관을 권한다.

## 직접 내보내기 (컴퓨터 조작 도구가 있을 때만)

컴퓨터 화면을 조작하는 도구가 연결되어 있고 카카오톡 PC 앱이 실행 중이며 사용자가 동의한 경우에 한해:

1. `상태.json` 의 `업무_대화방` 에 있는 방만 대상으로 한다. 목록에 없는 방은 열지 않는다.
2. 방마다 위 PC/Mac 절차대로 대화 내보내기를 실행해 `카카오톡/내보내기/` 에 저장한다.
3. 메시지를 입력하거나 보내지 않는다. 읽음 표시가 바뀔 수 있다는 점을 미리 알린다.
4. 끝나면 어떤 방을 내보냈는지 보고한다.
