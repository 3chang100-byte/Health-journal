# 카카오톡 업무 모니터 (Cowork 플러그인)

업무용 카카오톡 대화방에서 나온 일정, 할 일, 결정사항, 아이디어를 정리하고, 나중에 다시 물어보면 찾아 줍니다.

## 사용법

1. Cowork에서 작업 폴더를 고릅니다. 처음 실행하면 그 안에 `카카오톡/내보내기/` 폴더가 생깁니다.
2. 업무 대화방에서 **대화 내보내기**를 해서 그 폴더에 넣습니다. (PC: 대화방 ≡ → 대화 내용 → 대화 내보내기)
3. Cowork에 이렇게 말합니다.
   - "카카오톡 업무내용 정리"
   - "카톡에서 나온 이번 주 일정 알려줘"
   - "영업팀 방에서 얘기한 견적서 아이디어 뭐였지?"
   - "카톡에서 내가 맡은 일 정리해줘"

정리 결과는 `카카오톡/정리/` 에 날짜별 파일로 쌓이고, 읽은 대화는 `카카오톡/보관함.jsonl` 에 누적되어 예전 내용도 찾을 수 있습니다.

## 알아둘 점

- 카카오톡은 대화방을 읽는 공식 API가 없어서, 대화는 내보내기 파일로만 들어옵니다. 최신 내용을 반영하려면 다시 내보내 넣어야 합니다. 같은 방을 여러 번 넣어도 중복되지 않습니다.
- Windows, Mac, Android, iPhone 내보내기 형식(.txt, .csv, .zip)을 모두 읽습니다.
- 캘린더나 노션이 Cowork에 연결되어 있으면 정리 후 일정·할 일 등록을 제안합니다. 확인 없이 등록하지 않습니다.
- 대화 원문과 보관함은 작업 폴더에만 저장됩니다.

## 구성

| 구성 요소 | 내용 |
|---|---|
| 스킬 `kakaotalk-work-digest` | 정리와 검색 절차, 분류 기준, 내보내기 안내 |
| `scripts/kakao_parse.py` | 내보내기 파일 파서 (기간, 방, 사람, 키워드 필터, 보관함 누적) |
