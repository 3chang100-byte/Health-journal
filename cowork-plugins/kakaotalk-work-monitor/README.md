# 카카오톡 업무 모니터 (Cowork 플러그인)

업무용 카카오톡 대화방에서 나온 일정, 할 일, 결정사항, 아이디어를 정리하고, 나중에 다시 물어보면 찾아 줍니다.

## 사용법

1. 컴퓨터에 카카오톡 PC 앱을 설치하고 로그인해 둡니다.
2. Cowork에서 작업 폴더를 고르고, 컴퓨터 조작(computer use) 권한을 허용합니다.
3. Cowork에 이렇게 말합니다.
   - "카카오톡 업무내용 정리"
   - "카톡에서 나온 이번 주 일정 알려줘"
   - "영업팀 방에서 얘기한 견적서 아이디어 뭐였지?"
   - "율량점 프로젝트 방에 '내일 10시 현장 미팅 확정입니다' 보내줘" (글)
   - "견적서.pdf 를 삼창수산 x 이화마을 방에 보내줘" (파일)
   - "이번 주 정리를 문서로 만들어서 도전! 방에 보내줘" (문서)
   - "매일 아침 9시에 카카오톡 업무내용 정리해줘" (예약 실행)

처음 한 번만 어떤 방이 업무용인지 묻습니다. 그다음부터는 Claude가 카카오톡 앱에서 그 방들의 대화를 직접 내보내 읽습니다. 파일을 따로 넣을 필요가 없습니다.

정리 결과는 `카카오톡/정리/` 에 날짜별 파일로 쌓이고, 읽은 대화는 `카카오톡/보관함.jsonl` 에 누적되어 예전 내용도 찾을 수 있습니다.

## 알아둘 점

- 카카오톡은 대화방을 읽는 공식 API가 없어서, Claude가 사용자 컴퓨터의 카카오톡 앱을 직접 조작해 가져옵니다. 수집하는 동안 화면에서 카카오톡 창이 열리고 닫힙니다.
- 대화방을 열기 때문에 **그 방의 안 읽은 메시지가 읽음 처리**됩니다.
- 지정한 업무 대화방만 엽니다.
- **보내기**: 요청하면 대화방에 글, 파일, 문서를 보냅니다. 받는 방과 문구·파일 이름을 먼저 보여 주고, "보내"라고 확인해야만 전송합니다. 예약 실행 중에는 보내지 않습니다. 보낸 내용은 `카카오톡/보낸메시지.md` 에 기록됩니다. 상대가 읽은 뒤에는 되돌릴 수 없으니 확인 화면의 방 이름과 내용을 꼭 봐 주세요.
- 컴퓨터 조작을 쓸 수 없는 환경에서는 직접 내보낸 파일(.txt, .csv, .zip)을 `카카오톡/내보내기/` 에 넣어도 됩니다.
- 캘린더나 노션이 Cowork에 연결되어 있으면 정리 후 일정·할 일 등록을 제안합니다. 확인 없이 등록하지 않습니다.
- 대화 원문과 보관함은 작업 폴더에만 저장됩니다.

## 구성

| 구성 요소 | 내용 |
|---|---|
| 스킬 `kakaotalk-work-digest` | 자동 수집, 정리와 검색, 글·파일·문서 보내기 절차 |
| `scripts/kakao_parse.py` | 내보내기 파일 파서 (기간, 방, 사람, 키워드 필터, 보관함 누적) |
