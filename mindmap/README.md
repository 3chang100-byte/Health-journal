# 프로젝트 마인드맵 PWA

프로젝트를 가지로 펼치고, 가지마다 할 일 상태·마감일·메모를 붙여 한 장에서 관리하는 마인드맵 앱입니다.
서버 없이 브라우저(기기)에만 저장되고, 휴대폰 홈 화면에 추가하면 일반 앱처럼 열립니다.

## 기능

- **주제별 템플릿**: 새 마인드맵을 만들 때 앱 만들기 · 사업 확장 · 개인 프로젝트 · 자유 프로젝트 중 고르면 그에 맞는 가지가 미리 채워집니다.
- **공원**: 프로젝트가 주제별 구역(앱 만들기 · 사업 확장 · 개인 정원 · 기타)에서 나무 · 열매 나무 · 꽃 · 덤불로 자랍니다. 할 일을 끝낼수록 자라고, 프로젝트를 완료하면 다 자란 모습으로 남습니다. 완료한 프로젝트 수에 따라 공원 단계가 올라갑니다.
- **식물 확대 보기**: 공원의 식물을 누르면 가지(나무) · 꽃잎(꽃) · 덩이(덤불)로 그 프로젝트의 마인드맵을 보여 줍니다.

- 마인드맵 여러 개 만들기 · 복제 · 삭제
- 가지 추가/수정/삭제, 접기/펼치기, 끌어서 다른 가지로 옮기기, 가지 색 바꾸기
- 가지별 상태(할 일 → 진행 중 → 완료), 마감일, 메모 · 상위 가지와 상단에 진행률 표시
- 할 일 목록: 상태별로 모아 보고, 누르면 해당 가지로 이동
- 양쪽/오른쪽 펼침 전환, 확대·축소·화면 맞춤, 실행 취소/다시 실행
- JSON 내보내기/가져오기(백업), 다크 모드, 오프라인 사용
- **Claude로 보내기**: 마인드맵을 정리한 요청문을 만들어 코워크 또는 클로드 코드 입력란에 채워 줍니다. '요약 보고서'와 '앱 만들기' 중 고를 수 있고, 선택한 가지만 보낼 수도 있습니다.
- **캘린더에 추가**: 마감일이 있거나 이름에 날짜(예: `12/3`, `12월 3일`, `2026-12-03`)가 적힌 가지를 모아 Google 캘린더로 열거나 `.ics` 파일로 한 번에 받습니다.

## 조작법

| 동작 | 터치 | 키보드/마우스 |
| --- | --- | --- |
| 선택 | 가지 탭 | 클릭, 방향키 |
| 이름 수정 | 두 번 탭 또는 **수정** | 더블클릭, `F2` |
| 하위 가지 추가 | **하위** | `Tab` |
| 형제 가지 추가 | **형제** | `Enter` |
| 삭제 | **삭제** | `Delete` |
| 접기/펼치기 | 가지 옆 동그라미 | `Space` |
| 다른 가지로 옮기기 | 길게 눌러 끌기 | 끌어서 놓기 |
| 화면 이동 / 확대 | 한 손가락 끌기 / 두 손가락 벌리기 | 끌기·휠 / `Ctrl`+휠 |
| 실행 취소 / 다시 실행 | 상단 화살표 | `Ctrl+Z` / `Ctrl+Shift+Z` |

수정 중에는 `Enter`로 완료, `Shift+Enter`로 줄바꿈, `Esc`로 취소합니다.

## Claude로 보내기가 동작하는 방식

- **코워크로 보내기**는 `claude://cowork/new?q=…` 링크를 엽니다. Claude 데스크톱 앱이 설치된 컴퓨터에서만 열립니다.
- **클로드 코드로 보내기**는 새 탭에서 `https://claude.ai/code?prompt=…`를 엽니다.
- **보낼 채팅방 고르기**: 기본은 '새 채팅방'입니다. 기존 채팅방으로 보내려면 '채팅방 주소 추가'로 claude.ai 채팅방 주소를 이름과 함께 저장해 두고 고르면, 내용을 복사한 뒤 그 채팅방을 새 탭에서 엽니다(입력란에 붙여 넣어 보내기). 저장한 채팅방은 이 기기에만 보관됩니다.
- Claude 안에서 여는 미리보기 페이지에서는 '내 채팅방 불러오기'로 실제 채팅방 목록을 가져와, 고른 채팅방에 바로 전송할 수 있습니다.
- 새 채팅방으로 보낼 때는 내용이 입력란에 채워지기만 하고 자동으로 전송되지는 않습니다. 전체 내용은 항상 클립보드에도 복사됩니다.
- 마인드맵이 길어 주소에 다 담기지 않으면 지시문만 채워지므로, 열린 입력란에 붙여 넣으면 됩니다.

## 배포 (Vercel)

저장소를 Vercel에 연결할 때 **Root Directory를 `mindmap`** 으로 지정하면 됩니다. (Framework: Vite, 나머지는 기본값)

## 데이터

모든 내용은 이 기기 브라우저의 localStorage에만 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에
목록 화면의 **전체 백업**으로 JSON 파일을 받아 두고, 새 기기에서 **가져오기**로 불러오세요.
