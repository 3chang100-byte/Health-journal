# 생각의 정원

프로젝트를 가지로 펼치고, 가지마다 할 일 상태·마감일·메모를 붙여 한 장에서 관리하는 마인드맵 앱입니다.
서버 없이 브라우저(기기)에만 저장되고, 휴대폰 홈 화면에 추가하면 일반 앱처럼 열립니다.

## 기능

- **녹음으로 심기**: 녹음 내용을 마인드맵으로 만듭니다. 대본·요약 글 파일(.txt, .md, .srt, .vtt)을 올리거나 붙여 넣으면 제목(#)과 글머리표(-) 구조대로 가지가 되고, 긴 문장은 짧은 가지 이름과 메모로 나뉩니다. Claude 안에서 연 미리보기 페이지에서는 플라우드 녹음을 골라 요약 노트나 전체 대본을 바로 가져오고, Claude에게 주제별 정리와 할 일 추출을 맡길 수 있습니다. 음성 파일 자체를 글로 바꾸는 기능은 아직 없습니다.
- **새로 심기**: 심을 구역(앱 만들기 · 사업 확장 · 개인 정원 · 기타)만 고르면 빈 마인드맵으로 시작합니다. 구역은 나중에 바꿀 수 있습니다.
- **정원이 첫 화면**: 마인드맵을 시작하면 바로 주제별 구역(앱 만들기 · 사업 확장 · 개인 정원 · 기타)에 나무 · 열매 나무 · 꽃 · 덤불로 심기고, 할 일을 끝낼수록 자랍니다(완료하면 다 자란 모습). 식물을 누르면 그 마인드맵 편집 화면이 열립니다. 정원에는 물을 주고, 갈퀴질하고, 수레를 미는 사람들이 움직입니다.
- **식물로 보기**: 편집 화면 메뉴에서 그 마인드맵을 가지와 잎(나무) · 꽃잎(꽃) · 덩이(덤불)로 확대해 볼 수 있습니다.

- 마인드맵 여러 개 만들기 · 복제 · 삭제
- 가지 추가/수정/삭제, 접기/펼치기, 끌어서 다른 가지로 옮기기, 가지 색 바꾸기
- **가지를 새 마인드맵으로 심기**: 가지를 선택하고 '심기'를 누르면 그 가지와 하위 가지가 새 마인드맵이 되어 정원에 심깁니다. 원래 가지에는 화살표 표시가 남고, 누르면 새 마인드맵으로 이동합니다. 새 마인드맵 위쪽의 표시를 누르면 원래 마인드맵으로 돌아옵니다.
- **완료 버튼**: 편집 화면 왼쪽 아래의 '완료'를 누르면 그 마인드맵이 완료로 표시되고 정원에서 다 자란 모습이 됩니다. 다시 누르면 취소됩니다.
- 가지별 상태(할 일 → 진행 중 → 완료), 마감일, 메모 · 상위 가지와 상단에 진행률 표시
- 할 일 목록: 상태별로 모아 보고, 누르면 해당 가지로 이동
- 양쪽/오른쪽 펼침 전환, 확대·축소·화면 맞춤, 실행 취소/다시 실행
- JSON 내보내기/가져오기(백업), 다크 모드, 오프라인 사용
- **요약 복사**: 마인드맵을 요약과 함께 정리한 글을 만들어 보여 줍니다. '요약 보고서'와 '앱 만들기' 중 고르고, 필요하면 고쳐 쓴 뒤 복사해 Claude에 붙여 넣으면 됩니다. 선택한 가지만 담을 수도 있습니다. '일정 요약'을 고르면 마감일이 있거나 이름에 날짜가 적힌 가지를 날짜순으로 한 줄씩 정리해, 상대방에게 메시지로 바로 보낼 수 있는 짧은 일정 안내를 만들어 줍니다(끝낸 일정 제외).
- **캘린더에 추가**: 마감일이 있거나 이름에 날짜(예: `12/3`, `12월 3일`, `2026-12-03`)가 적힌 가지를 모아 Google 캘린더로 열거나 `.ics` 파일로 한 번에 받습니다.

## 조작법

| 동작 | 터치 | 키보드/마우스 |
| --- | --- | --- |
| 선택 | 가지 탭 | 클릭, 방향키 |
| 이름 수정 | 두 번 탭 또는 **수정** | 더블클릭, `F2` |
| 하위 가지 추가 | **하위** | `Tab` |
| 형제 가지 추가 | **형제** | `Enter` |
| 삭제 | **삭제** | `Delete` |
| 접기/펼치기 | 가지 옆 동그라미 | `Space` |
| 다른 가지로 옮기기 | 길게 눌러 끌기 | 끌어서 놓기 |
| 화면 이동 / 확대 | 한 손가락 끌기 / 두 손가락 벌리기 | 끌기·휠 / `Ctrl`+휠 |
| 실행 취소 / 다시 실행 | 상단 화살표 | `Ctrl+Z` / `Ctrl+Shift+Z` |

삭제는 기본으로 선택한 가지만 지우고 하위 가지는 한 단계 위로 올립니다. 하위 가지가 있으면 '하위 가지까지 모두 삭제'를 고를 수 있습니다.

수정 중에는 `Enter`로 완료, `Shift+Enter`로 줄바꿈, `Esc`로 취소합니다.

## 배포

**GitHub Pages (자동)**: `main` 브랜치에 `mindmap/` 변경이 올라가면 `.github/workflows/deploy-mindmap.yml`이 빌드해서 배포합니다. 처음 한 번만 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요. 주소는 `https://<사용자>.github.io/<저장소>/` 입니다.

**Vercel**: 저장소를 연결할 때 **Root Directory를 `mindmap`** 으로 지정하면 됩니다. (Framework: Vite, 나머지는 기본값)

## 데이터

모든 내용은 먼저 이 기기 브라우저의 localStorage에 자동 저장됩니다.

**기기 간 동기화 (선택)**: 정원 화면의 '동기화 켜기'에서 GitHub 연결 키(gist 권한만 있는 토큰)를 넣으면, 본인 GitHub 계정의 비밀 Gist 하나에 마인드맵 전체가 저장되어 여러 기기에서 같은 내용을 봅니다. 기기마다 같은 키를 한 번씩 넣으면 됩니다.

- 고친 뒤 몇 초 지나면 자동으로 올리고, 앱을 열거나 화면으로 돌아올 때와 2분마다 다른 기기의 변경을 받아 옵니다.
- 같은 마인드맵을 두 기기에서 동시에 고치면 나중에 고친 쪽이 남습니다(마인드맵 단위).
- 지운 마인드맵은 다른 기기에서도 지워집니다.
- 키는 그 기기의 브라우저에만 보관됩니다. 비밀 Gist는 목록에 나오지 않지만, 주소를 아는 사람은 열어 볼 수 있습니다.
- Claude 안의 미리보기 페이지에서는 외부 연결이 막혀 있어 동기화를 쓸 수 없습니다.

동기화를 쓰지 않을 때는 목록 화면의 **전체 백업**으로 JSON 파일을 받아 두고, 새 기기에서 **가져오기**로 불러오세요.
