# 생각의 정원

프로젝트를 가지로 펼치고, 가지마다 할 일 상태·마감일·메모를 붙여 한 장에서 관리하는 마인드맵 앱입니다.
서버 없이 브라우저(기기)에만 저장되고, 휴대폰 홈 화면에 추가하면 일반 앱처럼 열립니다.

## 기능

- **첫 화면이 작업공간**: 앱을 열면 바로 마인드맵을 그리는 넓은 캔버스가 나옵니다. 마지막으로 보던 자리와 배율을 기억합니다.
- **한 공간에 여러 마인드맵**: 빈 곳을 두 번 누르거나 '새 씨앗'을 누르면 그 자리에 새 마인드맵의 중심 주제가 심깁니다. 각 마인드맵은 심은 자리에 고정되고, 중심 주제를 끌면 마인드맵 전체가 옮겨집니다.
- **축소하면 한눈에**: 축소할수록 더 많은 마인드맵이 보입니다. 어느 정도 축소하면 제목과 큰 가지만, 더 축소하면 제목만 보입니다. 제목을 두 번 누르면 그 마인드맵으로 확대됩니다.
- **가지 편집**: 추가 · 수정 · 삭제(선택한 가지만 또는 하위까지), 접기, 끌어서 다른 가지나 다른 마인드맵으로 옮기기, 실행 취소
- **따로 심기**: 가지를 하위 가지와 함께 독립된 마인드맵으로 떼어 냅니다. 원래 가지에는 화살표 표시가 남고, 누르면 그 마인드맵으로 이동합니다.
- **할 일 관리**: 가지별 상태(할 일 → 진행 중 → 완료) · 마감일 · 메모, 진행률, 할 일 목록. 가지를 완료로 바꾸면 그 아래 가지도 모두 완료로 처리됩니다.
- **요약 복사**: 요약 보고서 · 앱 만들기 요청문 · 메시지용 일정 안내를 만들어 복사합니다. 선택한 가지(또는 마인드맵)만 담을 수도 있습니다.
- **캘린더에 추가**: 마감일이 있거나 이름에 날짜가 적힌 가지를 Google 캘린더로 열거나 `.ics` 파일로 받습니다.
- **기기 간 동기화**: 메뉴(⋮)에서 켭니다. 아래 '데이터' 참고.
- **앱으로 설치**: 메뉴(⋮) → '앱으로 설치'. 설치한 뒤 작업 표시줄에 고정할 수 있습니다.
- **버튼 설명**: 버튼에 마우스를 올리면 무슨 기능인지 말풍선으로 알려 줍니다.

이전 버전의 정원 · 목록 화면, 씨앗 종류, 녹음 가져오기, 백업 · 가져오기는 없앴습니다. 이전 버전에서 만든 마인드맵이 있는 기기에서는 처음 열 때 '새 프로젝트'만 남기고 나머지를 지울지 묻고, 백업 파일을 받은 뒤에만 지웁니다.

## 조작법

| 동작 | 터치 | 키보드/마우스 |
| --- | --- | --- |
| 선택 | 가지 탭 | 클릭, 방향키 |
| 이름 수정 | 두 번 탭 또는 **수정** | 더블클릭, `F2` |
| 하위 가지 추가 | **하위** | `Tab` |
| 형제 가지 추가 | **형제** | `Enter` |
| 삭제 | **삭제** | `Delete` |
| 접기/펼치기 | 가지 옆 동그라미 | `Space` |
| 다른 가지로 옮기기 | 길게 눌러 끌기 | 끌어서 놓기 |
| 화면 이동 / 확대 | 한 손가락 끌기 / 두 손가락 벌리기 | 끌기·휠 / `Ctrl`+휠 |
| 실행 취소 / 다시 실행 | 상단 화살표 | `Ctrl+Z` / `Ctrl+Shift+Z` |

삭제는 기본으로 선택한 가지만 지우고 하위 가지는 한 단계 위로 올립니다. 하위 가지가 있으면 '하위 가지까지 모두 삭제'를 고를 수 있습니다.

수정 중에는 `Enter`로 완료, `Shift+Enter`로 줄바꿈, `Esc`로 취소합니다.

## 배포

**GitHub Pages (자동)**: `main` 브랜치에 `mindmap/` 변경이 올라가면 `.github/workflows/deploy-mindmap.yml`이 빌드해서 배포합니다. 처음 한 번만 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요. 주소는 `https://<사용자>.github.io/<저장소>/` 입니다.

**Vercel**: 저장소를 연결할 때 **Root Directory를 `mindmap`** 으로 지정하면 됩니다. (Framework: Vite, 나머지는 기본값)

## 데이터

모든 내용은 먼저 이 기기 브라우저의 localStorage에 자동 저장됩니다.

**기기 간 동기화 (선택)**: 메뉴(⋮)의 '기기 간 동기화 켜기'에서 GitHub 연결 키(gist 권한만 있는 토큰)를 넣으면, 본인 GitHub 계정의 비밀 Gist 하나에 마인드맵 전체가 저장되어 여러 기기에서 같은 내용을 봅니다. 기기마다 같은 키를 한 번씩 넣으면 됩니다.

- 고친 뒤 몇 초 지나면 자동으로 올리고, 앱을 열거나 화면으로 돌아올 때와 2분마다 다른 기기의 변경을 받아 옵니다.
- 같은 마인드맵을 두 기기에서 동시에 고치면 나중에 고친 쪽이 남습니다(마인드맵 단위).
- 지운 마인드맵은 다른 기기에서도 지워집니다.
- 키는 그 기기의 브라우저에만 보관됩니다. 비밀 Gist는 목록에 나오지 않지만, 주소를 아는 사람은 열어 볼 수 있습니다.
- Claude 안의 미리보기 페이지에서는 외부 연결이 막혀 있어 동기화를 쓸 수 없습니다.
