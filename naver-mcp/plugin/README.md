# naver 플러그인

Claude(Cowork)에서 네이버를 다루는 플러그인입니다.

- 검색(뉴스·블로그·웹문서·이미지·지역), 검색어 트렌드, 쇼핑인사이트
- 카페 글쓰기(미리보기 후 승인하면 게시)
- 스마트스토어 상품·주문 조회(읽기 전용)
- 주소↔좌표, 자동차 길찾기

## 설치 후 할 일

1. Claude 에게 "네이버 연결 상태 확인해줘" 라고 말합니다. 키 파일을 둘 위치를 알려줍니다.
2. 그 위치에 `keys.env` 파일을 만들고 쓰려는 기능의 키만 한 줄에 하나씩 넣습니다.
   ```
   NAVER_HUB_KEY_ID=여기에_Client_ID
   NAVER_HUB_KEY=여기에_Client_Secret
   ```
3. 저장하면 바로 쓸 수 있습니다. "네이버 뉴스에서 ○○ 찾아줘" 처럼 말해 보세요.

키 이름과 발급처는 Claude 에게 "네이버 키 설정 방법 알려줘" 라고 물으면 안내합니다.

## 필요한 것

- Node.js 20.12 이상이 실행 환경에 있어야 합니다.
- 블로그 글 입력은 이 플러그인에 포함된 서버만으로는 동작하지 않습니다(브라우저 자동화 모듈 미포함).
